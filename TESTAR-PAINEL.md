# Teste do painel

Quando `supabase-config.js` ainda não tem credenciais, abra `admin.html` e use a senha `123456`. Faça um pedido pelo site e o painel poderá mostrá-lo se ambos forem abertos no mesmo navegador e origem. Os dados do modo de teste ficam somente no armazenamento local desse navegador.

Esse acesso é apenas para teste e não é uma senha segura para um painel publicado. Para receber pedidos de clientes em outros aparelhos e compartilhar alterações com a equipe, configure o Supabase seguindo `CONFIGURAR-PAINEL.md`.
